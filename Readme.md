# Chess

# Features that i have implemented as of now
pieces moves as they are in real chess it outputs check if its in check.

# Limitations

* No checkmate implemented yet and stalemate and castling and en passant and pawn promotion
* its not turn based currently.
* This may produce bugs that i dont know.

# Steaps to download

* from release download the p file and assets.zip.
* unzip assets
* make sure the p file has executable permission
* run the p file

I dont know if this work in wsl so its good to have a vm or real linux machine.

Currently this has no dependencies all are statically linked.
